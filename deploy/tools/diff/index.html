テキスト差分

2つの文章を比べて、増えた行と消えた行を色と記号で示します。

行頭・行末や連続する空白の違いを無視します。

Ctrl＋Enter（Mac は ⌘＋Enter）でも比較できます。

0追加された行（＋）
0削除された行（−）
0変更なしの行

「比較する」を押すと、ここに差分が表示されます。

＋ は追加、− は削除、≈ は空白だけの違いです。

使い方

  1. 2つの文章を左右の欄に貼ります。
  2. 比較するを押します。
  3. 色と記号で差分を確認します。

差分のしくみ

2つのテキストを行単位で比較し、追加・削除された行を並べます。文章やプログラム、設定ファイルの変更点を目で追うときに使います。

差分の求め方

最長共通部分列（LCS）を使い、両方に共通して現れる行の並びをできるだけ長く取り出します。そこに含まれない行を「削除（Aにだけある行）」と「追加（Bにだけある行）」として示します。行の順番は保たれるため、同じ行の移動は削除と追加の組になり、1行の中の小さな修正も行全体の削除と追加になります。

空白の扱いと表示

「空白の違いを無視する」をオンにすると、行頭・行末の空白を取り除き、連続する空白を1つにまとめて比べます。インデントや語間のスペースだけが違う行は「変更なし」とし、≈ を付けます。表示される本文は元のままで、CRLF と LF は常に同じ改行として扱います。

追加行は ＋ と緑、削除行は − と赤で示し、色が見分けにくい場合も記号で判別できます。1回の比較は各 5,000 行まで、比較表が 400 万セルを超える場合は中止します。表示は先頭 5,000 行までですが、集計はすべての行が対象です。
