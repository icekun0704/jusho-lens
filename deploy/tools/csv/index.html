CSV⇔JSON変換

CSVをJSONに、JSONをCSVに変換します。引用符で囲んだカンマ・改行・引用符を含むセルも、CSVの規則に沿って正しく扱います。

変換の向き

入力は2MBまでです。超える場合は分割して変換してください。

UTF-8として読み込みます。行数・列数は変換結果の数です（CSV→JSONではヘッダー行を除く）。

0行数
0列数
0 B入力サイズ
0 B出力サイズ

出力形式: CSV = UTF-8（BOM付き）・改行CRLF、JSON = UTF-8・改行LF。コピーするテキストにはBOMを付けません。

使い方

入力はブラウザ内で処理され、サーバーには送られません。

  1. 「変換の向き」で CSV → JSON か JSON → CSV を選びます。選ぶと見本のデータが切り替わります。
  2. CSV → JSON では「区切り文字」を選び、必要なら「1行目をヘッダー行として使う」をオンにします。オフの場合は各行が配列になります。
  3. 上の欄にデータを貼り付けるか、「サンプル」で見本を入れます。入力は変換のたびに自動で反映され、「変換する」または Ctrl+Enter（Macは ⌘+Enter）でも実行できます。
  4. 下の欄に変換結果が出ます。「結果をコピー」でクリップボードへ、「ダウンロード」でファイルに保存します。CSVはExcel向けにUTF-8（BOM付き）・CRLFで保存します。
  5. エラーが出たときは、引用符の閉じ忘れやJSONの形を確認してください。2MBを超える入力は分割して変換します。

CSV⇔JSON変換について

CSVは表をカンマで区切って並べたテキスト、JSONは配列やオブジェクトを構造として表すテキストです。この道具は2つの形式をブラウザ内で相互に変換します。入力した内容は送信されず、ページを閉じれば残りません。

CSVの書式

CSVの一般的な仕様はRFC 4180（2005年公開）にまとめられています。セルに区切り文字・引用符・改行を含めるときは、セル全体をダブルクォートで囲みます。セルの中にダブルクォートを入れたいときは、二重に書いてエスケープします（"特売" は "メモ: ""特売"" です"）。行の区切りはCRLFまたはLFで、この道具はどちらも読み分けます。

Excelが保存するCSVはShift_JISのことがあり、UTF-8として読むと文字化けします。その場合はExcel側で「CSV UTF-8」形式で保存し直してください。この道具が書き出すCSVはUTF-8で、Excelが文字コードを判別できるようBOMを付けています。

JSONとの違い

CSVのセルはすべて文字列として扱われ、数値・真偽値・nullの区別がありません。CSV → JSONでは値を文字列のまま出力するため、先頭が0の郵便番号や電話番号、桁の多いIDが壊れません。数値として使いたい場合は、変換後に受け取る側で型を変換してください。

JSON → CSVでは、オブジェクトの配列はキーをヘッダー行にして出力し、配列の配列はそのまま出力します。値がオブジェクトや配列に入れ子になっている場合は、その部分をJSON文字列にして1つのセルに収めます。オブジェクト・配列・単一の値が混在した配列は、形をそろえるようエラーにしています。

変換のルールと制限

CSV → JSONでヘッダーを使うとき、空の見出しは column1 のような名前になり、重複する見出しには _2 などの連番を付けます。データ行がヘッダーより多い場合は、余った列に column5 のような名前を追加します。空行は読み飛ばします。

入力の上限は2MBです。それを超えると変換せずにエラーを表示します。行数・列数そのものには固定の上限を設けていませんが、ブラウザのメモリの範囲で動作します。大量のデータは分割して変換してください。
