使い方

  1. HEX か RGB か HSL を入力します。
  2. 文字色と背景色を選びます。
  3. 表示された比率で合否を確かめます。

カラー変換とコントラスト

色を HEX・RGB・HSL の3形式で相互に変換し、文字色と背景色のコントラスト比を計算します。「明るくした色」「暗くした色」は白と黒を 15〜75% 混ぜて作り、押すと入力に反映されます。

HEX・RGB・HSL の関係

HEX は赤・緑・青を16進数2桁ずつ並べた表記で、#rrggbb の6桁は約1677万色を表します。3桁の #rgb は各桁を2回繰り返す省略形で、#f0c は #ff00cc と同じです。RGB は光の三原色の加算混合で、すべて0なら黒、すべて255なら白。HSL は色相 H（0〜360）、彩度 S、明度 L（0〜100%）で表し、H は 0 が赤、120 が緑、240 が青です。計算は sRGB・8ビット前提で、CMYK や Display P3 の変換は行いません。

コントラスト比の求め方

各成分を0〜1に直し、0.03928 以下なら12.92で割り、それより大きければ ((c + 0.055) / 1.055) ^ 2.4 を適用します。赤 0.2126・緑 0.7152・青 0.0722 の重みで足したものが相対輝度で、比は (L1 + 0.05) / (L2 + 0.05) です。同じ色なら1:1、黒と白なら約21:1 になります。

WCAG 2.1 では、通常テキストは AA 4.5:1・AAA 7:1、大きなテキストは AA 3:1・AAA 4.5:1 です。比は小数第2位に丸め、表示と同じ値で合否を判定します。
