JSON整形

JSON を2スペースで整形、または1行に圧縮します。構文エラーは行・列と該当箇所を表示します。

0 文字 / 0 バイト

使い方

入力はブラウザ内で処理され、サーバーには送られません。

  1. 入力欄に JSON を貼り付けるか、「サンプル」を押します。
  2. 「整形（2スペース）」で読みやすく、「圧縮」で空白を除いた1行にします。「検証」は構文が正しいかだけを確認します。
  3. 「キーをソート」を入れると、オブジェクトのキーを辞書順に並べ替えます。配列の要素の順序は変わりません。
  4. 結果は「コピー」でクリップボードへ、「ダウンロード（.json）」でファイルに保存できます。
  5. 不正な JSON のときは、行・列と該当箇所の前後を表示します。「クリア」で入力と結果を空にできます。

JSON整形について

JSON（JavaScript Object Notation）は RFC 8259 で定義されたテキスト形式で、Web API の応答や設定ファイルで広く使われます。このツールは入力を JSON.parse で読み、2スペースのインデントで整形するか、空白を除いて1行に圧縮します。整形は差分の確認や目視での点検に、圧縮はファイルサイズを抑えたいときに使います。処理はすべてブラウザ内で完結し、入力は送信されません。

構文エラーの表示

不正な JSON を渡すと、行・列と該当箇所の前後を表示します。ブラウザの JSON.parse が返すエラーメッセージは実装ごとに異なるため、このツールは独自の簡易スキャナで最初のエラー位置を推定しています。完全な構文解析ではないため、表示される位置は目安としてください。全角の引用符（“ ”）や、見えない BOM が先頭に付いたファイルも、エラーとして検出します。

知っておきたい制限

  • 数値は JavaScript の倍精度浮動小数として扱うため、16 桁を超える整数は精度が落ちる場合があります（9007199254740993 など）。金額や ID は文字列で扱うのが安全です。
  • 同じキーが重複した場合、後の値だけが残ります。
  • コメント（//）と末尾のカンマは JSON の仕様にないため、エラーになります。
  • 入力の上限は 2 MB です。超えた場合は処理を中止するので、ファイルを分けてください。
