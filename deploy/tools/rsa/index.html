RSA暗号化・復号

ブラウザ内で RSA-OAEP（SHA-256）の鍵生成・暗号化・復号を行うデモです。公開鍵と秘密鍵の PEM をそのまま貼り付けて試せます。

1. 鍵を生成

RSA-OAEP（SHA-256）の鍵ペアを作ります。鍵はページのメモリ上にだけ保持し、送信も保存もしません。

鍵を生成すると、ここに秘密鍵（PKCS#8, PEM）が入ります。秘密鍵は「秘密鍵を表示する」にチェックを入れたときだけ表示されます。

2. 公開鍵で暗号化

公開鍵の PEM と平文を入れてください。暗号文は Base64 で出力します。鍵を生成した直後は、公開鍵が下の欄に自動で入っています。

3. 秘密鍵で復号

秘密鍵の PEM と Base64 の暗号文を入れます。直前に生成した鍵なら、秘密鍵の欄は空のままで復号できます。

これは学習・確認用のデモです。本番の秘密情報の暗号化や秘密鍵の保管には使わないでください。鍵と入力はブラウザのメモリ上だけで扱い、送信・保存はしません。ページを閉じると失われます。

使い方

入力はブラウザ内で処理され、サーバーには送られません。

  1. 鍵長（2048 / 3072 / 4096 ビット）を選び、「鍵を生成」を押します。4096 ビットは数秒かかることがあります。
  2. 公開鍵は「2. 公開鍵で暗号化」の欄に自動で入ります。秘密鍵を見るには「秘密鍵を表示する」にチェックを入れます。コピーとダウンロードは非表示のままでも使えます。
  3. 平文を入れて「暗号化」を押すと、Base64 の暗号文が出ます。
  4. 暗号文を「3. 秘密鍵で復号」に貼り、「復号」を押します。直前に生成した鍵なら秘密鍵の欄は空のままで構いません。
  5. 別の道具で作った鍵を使うときは、公開鍵（SPKI）と秘密鍵（PKCS#8）の PEM をそれぞれの欄に貼り付けます。

RSA暗号化・復号について

RSA は公開鍵暗号の一つで、公開鍵で暗号化した内容は、対になる秘密鍵でしか復号できません。このページはブラウザの Web Crypto API にある RSA-OAEP（ハッシュ SHA-256）を使います。OAEP はパディング方式の一つで、同じ平文でも暗号化のたびに異なる暗号文になります。復号結果が同じ平文になるので、暗号文を比べても内容は推測できません。

RSA で一度に暗号化できるデータ量は鍵長から決まり、「鍵長（ビット）÷ 8 − 66 バイト」が上限です。2048 ビットなら 190 バイト、3072 ビットなら 318 バイト、4096 ビットなら 446 バイトまでです。長い文書は AES などの共通鍵暗号で暗号化し、その鍵だけを RSA で包む「ハイブリッド暗号」が一般的で、TLS もこの方式を使っています。

鍵の形式

公開鍵は SPKI（-----BEGIN PUBLIC KEY-----）、秘密鍵は PKCS#8（-----BEGIN PRIVATE KEY-----）の PEM 形式（RFC 7468）で入出力します。OpenSSL なら次のコマンドで作れます。

openssl genpkey -algorithm RSA -pkeyopt rsa_keygen_bits:2048 -out private-key.pem
openssl rsa -pubout -in private-key.pem -out public-key.pem

暗号文は Base64 の文字列で受け渡します。改行や空白が混ざっていても、復号のときに無視します。

注意

このページは仕組みを確かめるためのデモです。本番の秘密情報の暗号化や、秘密鍵の保管には使わないでください。鍵と入力はブラウザのメモリ上だけで扱い、サーバーへ送信したり、localStorage などに保存したりしません。ページを閉じると失われます。Web Crypto API は HTTPS または localhost でのみ動作します。

PKCS#1 形式（BEGIN RSA PRIVATE KEY、BEGIN RSA PUBLIC KEY）と、パスフレーズ付きの秘密鍵（BEGIN ENCRYPTED PRIVATE KEY）には対応していません。パスフレーズ付きの鍵は、OpenSSL の openssl pkcs8 -topk8 -nocrypt で暗号化を外した PKCS#8 に変換してから使ってください。
