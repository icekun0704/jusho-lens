ハッシュのしくみ

ハッシュ関数は、任意の長さのデータから固定長の値を作る一方向の計算です。同じ入力からは必ず同じ値になり、1文字でも変われば結果はまったく別になります。元のデータを復元することは事実上できません。ファイルの同一性確認や改ざん検出、ダウンロードしたファイルの照合に使います。

方式の選び方

ふだん使うなら SHA-256 が標準的です。SHA-384 と SHA-512 はより長い値を返します。SHA-1 は2017年に、同じハッシュ値になる別のデータを作れることが示されました。署名や改ざん検出には使わず、古いシステムとの互換性確認に限ってください。

テキストとファイルの違い

テキストは UTF-8 のバイト列を計算します。同じ文字でも文字コードや改行コード（LF と CRLF）が違えば値は変わります。ファイルは中身のバイト列をそのまま読むため、ファイル名や拡張子は結果に影響しません。数百 MB を超えるファイルは時間とメモリに余裕をもって実行してください。
