画像変換・圧縮

画像を WebP・JPEG・PNG に変換し、軽くして保存できます。

またはこの枠にドラッグ&ドロップ（PNG・JPEG・WebP・GIF・BMP・AVIF）

使い方

  1. 画像を選ぶか枠に落とします。
  2. 形式・品質・最大幅を決めます。
  3. 変換して保存します。

画像変換のしくみ

選んだ画像をブラウザ内で読み込み、canvas に描いてから指定した形式で書き出します。WebP と JPEG は品質を 0.5〜0.95 で指定でき、下げるほど小さくなります。最大幅を指定すると、横長の画像は縦横比を保ったまま縮小されます。

形式の違い

WebP は写真でも透過でも扱え、同程度の見た目なら JPEG や PNG より小さくなることが多い形式です。JPEG は透過を保持できず、透過部分は白で塗られます。PNG は可逆圧縮で画質は劣化しませんが、写真では大きくなります。GIF やアニメーション付き WebP は最初のフレームだけを書き出し、SVG には対応していません。

注意点

canvas を経由するため、撮影日時やカメラ情報などの Exif は出力に含まれません。元の解像度が非常に大きい画像は、メモリ不足で変換に失敗することがあります。WebP に対応していないブラウザでは自動で JPEG で出力し、その旨を各ファイルに表示します。
