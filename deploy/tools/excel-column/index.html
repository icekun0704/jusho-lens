Excel列番号変換

表計算の列番号と列字母を相互に変換します。範囲の列数も数えられます。

列番号と列字母

どちらかを入れると、もう一方がすぐ変わります。1〜16384（XFD）まで。

27 列目は AA 列です。

列字母は小文字でもかまいません。

範囲の列数

A:C や A1:C5 の範囲で、含まれる列数を数えます。

3列数
A開始列
C終了列

A列からC列まで、3列です。

1 → A26 → Z27 → AA702 → ZZ703 → AAA16384 → XFD

使い方

列番号の計算は端末内だけで行います。

  1. 列番号か列字母を入力します。
  2. もう一方の表記にすぐ切り替わります。
  3. A:C の形で範囲の列数を数えます。

変換のしくみ

表計算ソフトの列には、A、B、…、Z、AA、AB、… と名前が付きます。26進数に似ていますが、0に当たる文字がないため、Z の次は AA、ZZ の次は AAA になります。27列目が AA、52列目が AZ、53列目が BA です。

列番号から字母へは、番号から1を引いた値を26で割った余りを文字に直し、商を繰り返すと求められます。逆向きは、各文字を A=1 〜 Z=26 の数に置き換え、26を掛けて足していきます。

Excel と Google スプレッドシートは、どちらも 16384 列（XFD）まで扱えます。範囲 A:C の列数は、C の 3 から A の 1 を引いて 1 を足した 3 です。開始と終了が同じ A:A なら1列になります。範囲を逆に書いた C:A も、同じ3列として数えます。

使う場面

A1形式の参照では列が字母、VBA の Cells(行, 列) や一部のAPIでは列が番号で指定されます。同じ列を別の書き方に直すとき、番号と字母がずれていないか確かめられます。数式の COLUMN() が使えない場面でも、変換した字母をそのまま参照に書けます。

列番号は 1〜16384、列字母は A〜XFD までです。それを超える値はエラーとして表示します。全角の字母やコロンで入力しても、半角に直して読み取ります。
