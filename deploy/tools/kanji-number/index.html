漢数字・大字変換

算用数字と漢数字・大字を相互に変換し、領収書の金額欄の表記も作れます。

算用数字 → 漢数字・大字

0から9999兆までの整数に対応します。カンマや全角数字、「円」付きでも入力できます。

—漢数字
—大字
—領収書の金額欄（例）

大字は壱・弐・参・肆・伍・陸・漆・捌・玖・拾・百・阡・萬で表記します。領収書形式は例に合わせて「万」を使い、先頭に「金」、末尾に「円也」を付けます。

漢数字・大字 → 算用数字

漢数字・大字・位取り表記を算用数字に戻します。「金」「円」「也」やカンマは無視します。

—

負数・小数には対応していません。読み取れない文字がある場合は、その文字を示してエラーを表示します。

使い方

変換結果はボタンからコピーできます。

  1. 算用数字を入力します。
  2. 漢数字・大字を確かめます。
  3. 逆変換も下の欄でできます。

漢数字と大字の書き方

漢数字は一・二・十・百・万のように位を表す字で数を書きます。大字は壱・弐・拾・阡・萬など画数の多い字を使い、書き換えを防ぐために領収書や契約書の金額欄で使われます。

位取りの書き方

通常の漢数字では十・百の前の「一」は書きません（十五、百二十）。千は数の全体が1,000〜9,999なら「千」、万以上に付くときは「一千万」のように「一」を付けます。途中の0は書かないため、1,005は「千五」、10,100は「一万百」です。大字では「壱拾」「壱阡」のように「壱」を省きません。

使える範囲と注意

変換できるのは0から9999兆9999億9999万9999までの整数で、負数と小数には対応しません。逆変換は通常の漢数字・大字のほか、「二〇二六」のような位取りや「3万5千」のような混在表記も読み取ります。大字の字体は書式によって異なり、四〜九を肆・伍・陸・漆・捌・玖、百を佰、千を仟と書くこともあります。記入は取引先や提出先の書式に合わせてください。
