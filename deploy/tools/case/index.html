文字種変換

1つの文字列から、命名規則11種類の変換結果をまとめて作ります。各行のコピーボタンで、必要な形式だけを取り出せます。

スペース・アンダースコア・ハイフン・英字の大文字小文字の切り替わりを、単語の区切りとして扱います。

使い方

入力はブラウザ内で処理され、サーバーには送られません。

  1. 「変換する文字列」欄に、変換したい単語や識別子を入力します。結果は入力のたびに更新されます。
  2. 表の「結果」列に、camelCase・PascalCase・snake_case・kebab-case・CONSTANT_CASE・大文字・小文字・全角半角・かな変換の11種類が並びます。
  3. 必要な行の「コピー」を押すと、その形式の文字列だけがクリップボードに入ります。「すべてコピー」は「形式: 結果」の一覧をまとめてコピーします。
  4. 「サンプルを入れる」で動作を確認できます。「クリア」で入力と結果を空にします。

文字種変換について

プログラムの識別子やファイル名では、単語の区切り方を揃えるために命名規則が使われます。この道具は、入力した文字列を単語に分け、代表的な11種類の形式へ一括で変換します。処理はブラウザ内だけで完結し、入力内容は送信されません。

単語の分け方

英単語の区切りとして、スペース、アンダースコア、ハイフンを扱います。加えて、getHTTPResponse のような連結文字列は、小文字から大文字への切り替わりと、連続する大文字の末尾で分割し、get・HTTP・Response とみなします。camelCase は先頭の語を小文字にして残りの語の頭を大文字にし、PascalCase はすべての語の頭を大文字にします。snake_case と kebab-case は小文字を _ と - で、CONSTANT_CASE は大文字を _ で連結します。

この分割はスペルや意味を理解するものではなく、文字の並びだけを見る簡易的な判定です。すべて大文字の略語は先頭だけ大文字に整えられ、日本語や記号だけの語はそのまま残ります。変換結果が意図どおりかは、表を見て確認してください。

全角・半角の変換

全角英数→半角は、Unicode の全角形（U+FF01〜U+FF5E）を、対応する半角の ASCII 文字（U+0021〜U+007E）へ置き換えます。半角英数→全角はその逆です。英数字だけでなく、全角の記号も半角の記号へ、半角の記号も全角の記号へ変換します。全角スペース（U+3000）と半角スペースは、どちらの変換でも変更しません。半角カタカナ（U+FF61〜U+FF9F）は対象外です。

ひらがな・カタカナの変換

ひらがなとカタカナは、Unicode 上で多くが 0x60 の差で対応しています。この道具は、ひらがな U+3041〜U+3096 と繰り返し記号 ゝゞ をカタカナへ、カタカナ U+30A1〜U+30F6 と繰り返し記号 ヽヾ をひらがなへ変換します。長音符「ー」は共通の文字なので変更しません。ヷ・ヸ・ヹ・ヺ は対応するひらがながないため、そのまま残ります。半角カタカナは変換しません。
