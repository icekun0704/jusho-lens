文字種変換

ひとつの単語から、命名規則11種類の結果をまとめて作ります。

スペース・ハイフン・大文字小文字の切り替わりで単語を区切ります。

    使い方

    1. 変換したい単語を入力します。
    2. 一覧から使う形式を選びます。
    3. コピーを押して貼り付けます。

    11種類の変換

    プログラムの識別子やファイル名では、単語の区切り方を揃えるために命名規則が使われます。入力した文字列を単語に分け、代表的な 11 種類の形式へ一括で変換します。

    単語の分け方

    スペース、アンダースコア、ハイフンを区切りとして扱います。getHTTPResponse のような連結文字列は、小文字から大文字への切り替わりと、連続する大文字の末尾で分け、get・HTTP・Response とみなします。camelCase は先頭を小文字、PascalCase はすべての語頭を大文字にし、snake_case と kebab-case は _ と - でつなぎます。スペルや意味は読まず、文字の並びだけで判定します。

    全角・半角とかなの変換

    全角英数→半角は Unicode の全角形（U+FF01〜U+FF5E）を半角へ、半角→全角はその逆に置き換えます。全角スペース（U+3000）と半角スペースは変わりません。ひらがなとカタカナは U+3041〜U+3096 と U+30A1〜U+30F6 を対応させて変換し、長音符「ー」や対応するひらがながないヷ・ヸ・ヹ・ヺ はそのまま残ります。半角カタカナは対象外です。
