Base64変換

テキストやファイルをBase64に、Base64をテキストやファイルに変換します。日本語はUTF-8として扱い、処理はブラウザ内で完結します。

テキスト

日本語は UTF-8 のバイト列として変換します。Base64 側は標準形式と URL-safe 形式のどちらも読み取れます。

ファイル

ファイルは読み込んだ順に処理し、進捗を表示します。data URL は「data:種類;base64,」で始まる文字列です。

使い方

入力はブラウザ内で処理され、サーバーには送られません。

  1. テキストを Base64 にするには、左の欄にテキストを入力して「変換」を押します。
  2. Base64 をテキストに戻すには、右の欄に貼り付けて「変換」を押します。改行や空白、URL-safe 形式も受け付けます。
  3. URL-safe にしたい場合は、変換前にチェックを入れます。チェックを変えると、表示中の結果も作り直されます。
  4. ファイルは「ファイル → data URL」で選んで「変換」を押します。大きいファイルは進捗が表示されます。
  5. data URL や Base64 からファイルを作るには、下の欄に貼り付け、ファイル名を入れて「ダウンロード」を押します。

Base64とは

Base64 は、任意のバイト列を A–Z、a–z、0–9、+、/ の 64 種類の文字で表す符号化方式です。3 バイトを 4 文字に対応させるため、データ量は元の約 1.33 倍になります。データをテキストとして扱う場面（data URL、メールの添付、JSON の一部など）で使われます。暗号化ではないため、誰でも元に戻せます。

日本語と文字コード

この道具は、文字列を UTF-8 のバイト列に変換してから Base64 にします。逆方向では、バイト列を UTF-8 として解釈します。そのため日本語も文字化けせずに往復します。Base64 の入力に改行や空白が含まれていても無視し、- と _ を使う URL-safe 形式もそのまま読み取ります。UTF-8 として解釈できないバイト列は、テキストではなくファイルとして扱ってください。

URL-safe 形式と注意点

URL-safe 形式では + を - に、/ を _ に置き換え、末尾の =（パディング）を除きます。URL やファイル名の一部に使う場合に適しています。data URL は標準の Base64 を前提とするため、この道具のファイル変換では URL-safe を適用しません。

Base64 はデータを隠すものではありません。機密情報を Base64 にしただけで安全になるわけではなく、変換しても内容は誰でも取り出せます。処理はすべてブラウザ内で行われ、入力した内容がサーバーに送信されることはありません。
