Base64変換

テキストやファイルを Base64 にして、元に戻せます。

テキスト

日本語は UTF-8 として変換します。

ファイル

data URL は「data:種類;base64,」で始まる文字列です。

—元のサイズ
—Base64 の長さ
—data URL の長さ

使い方

  1. 左の欄にテキストを入れ、変換を押します。
  2. 右の欄に Base64 を貼り付けて戻します。
  3. ファイルは選んでダウンロードするだけです。

Base64 のしくみ

Base64 は、バイト列を A–Z、a–z、0–9、+、/ の 64 文字で表す符号化方式です。3 バイトが 4 文字になるため、データ量は約 1.33 倍に増えます。data URL やメールの添付など、バイナリをテキストとして扱う場面で使います。暗号化ではないので、誰でも元に戻せます。

日本語と文字コード

文字列は UTF-8 のバイト列にしてから変換するので、日本語も文字化けせずに往復します。Base64 側は改行や空白を無視し、- と _ を使う URL-safe 形式もそのまま読めます。UTF-8 として解釈できないデータは、テキストではなくファイルとして扱ってください。

URL-safe 形式と注意点

URL-safe 形式は + を - に、/ を _ に置き換え、末尾の = を省いたものです。URL やファイル名に埋め込むときに使います。data URL は標準の Base64 を前提とするため、ファイル変換では URL-safe を適用しません。

Base64 にしても内容は隠せません。機密情報をそのまま貼らないでください。
