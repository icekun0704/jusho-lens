使い方

入力はブラウザ内で処理され、サーバーには送られません。

  1. 「正規表現パターン」に、スラッシュで囲まずにパターン本体を入力します。例: \d{3}-\d{4}
  2. 必要に応じて g・i・m・s・u・y のフラグをオンにします。g をオフにすると最初の1件だけを調べます。
  3. 「対象テキスト」に検索したい文章を貼り付けます。入力のたびにハイライト・マッチ数・一覧が更新されます。
  4. 「プリセット」でメール・URL・電話番号・郵便番号・日付の代表的なパターンを試せます。「結果をコピー」でパターンとマッチ一覧をテキストとして取り出せます。

正規表現テスターについて

正規表現は、文字列の検索や置換に使われるパターンの書き方です。この道具は、ブラウザの JavaScript が持つ RegExp をそのまま使って、パターンと対象テキストの一致を調べます。入力内容はブラウザの外へ送られません。

フラグの意味

g は全体検索で、最初の一致で止めずにすべての一致を探します。i は大文字小文字を区別しません。m は複数行モードで、^ と $ が各行の先頭と末尾にも一致します。s は . が改行にも一致するようにします。u は Unicode モードで、サロゲートペアを1文字として扱い、\u{...} などの書き方が使えます。y は sticky モードで、lastIndex の位置から連続して一致する箇所だけを探します。g も y もオフのときは、最初の1件だけを表示します。

表示の読み方

「位置」は、対象テキストの先頭を0とした UTF-16 コード単位のオフセットです。日本語の多くは1文字が1コード単位ですが、絵文字などは2コード単位になります。「グループ」には、丸括弧で囲んだキャプチャグループが番号順に並びます。名前付きグループは (?<name>...) で定義でき、名前でも表示します。一致しなかったグループは「未参加」と表示します。長さ0の一致はハイライトせず、一覧に「(長さ0)」として残します。

制限と注意

対象テキストは100KB（102,400バイト）までで、超えた分は先頭から切り詰めて検証します。一致が多い場合は、ハイライトを先頭1,000件、一覧を先頭200件まで表示します。また、(a+)+ のような入れ子の繰り返しを含むパターンでは、一致に膨大な時間がかかることがあります（破滅的バックトラック）。JavaScript の正規表現は途中で中断できないため、そのようなパターンを長いテキストに当てるとタブが応答しなくなることがあります。心当たりのあるパターンは、短いテキストで試してください。
