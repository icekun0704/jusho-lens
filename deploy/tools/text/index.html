文字数カウント

貼り付けた文章の文字数・行数・段落数・読了時間・原稿用紙換算をその場で数えます。X・Instagram・noteの上限も並べて確認できます。

オプション

オプションは数値の数え方だけを変えます。コピーされるのは入力した本文そのものです。

0文字数（空白込み）
0文字数（空白除く）
0行数
0段落数
0英単語数
0日本語文字数
0秒読了時間（500字/分）
0.0原稿用紙（400字詰め・枚）

ひらがな 0・カタカナ 0・漢字 0

SNSの文字数上限

文字数（空白込み）と比べています。上限は変更されることがあるため、投稿前に各サービスの公式表示も確認してください。

SNSごとの文字数上限と、入力した文章の残り文字数
媒体上限残り
X（日本語）140字残り 140字
X（英語）280字残り 280字
Instagram キャプション2,200字残り 2,200字
note タイトル25字前後残り 25字

Xは日本語を1文字あたり2として数えるため、日本語の目安は140字です。noteは公式にタイトル15〜25文字程度がすすめられています。

使い方

入力はブラウザ内で処理され、サーバーには送られません。

  1. 「テキスト」欄に文章を貼り付けるか、直接入力します。数値は入力のたびに更新されます。
  2. 必要なら「連続する空白を1つに詰める」「改行を除いて数える」をオンにします。数値の数え方だけが変わり、本文は変わりません。
  3. 文字数・行数・段落数・読了時間・原稿用紙換算と、SNSごとの残り文字数を確認します。上限を超えると赤字で表示されます。
  4. 「本文をコピー」で入力した文章をそのままコピーできます。「クリア」で欄を空にします。

文字数カウントについて

入力した文章をその場で数える道具です。文章は外部に送信されず、ページを閉じれば残りません。

数え方

「文字数（空白込み）」は改行を含むすべての文字を数えます。絵文字などはコードポイント単位で数えるため、複数の絵文字を組み合わせたものは複数文字として数えることがあります。「文字数（空白除く）」は半角・全角の空白、改行、タブを除いた数です。行数は改行で区切った行の数、段落数は空行で区切られたまとまりの数です。英単語数はラテン文字の単語を数え、日本語文字数はひらがな・カタカナ・漢字の合計です（長音符「ー」はカタカナに含めます）。

読了時間は1分500字を目安に、空白を除いた文字数から計算しています。原稿用紙換算は400字で1枚として、改行を除いた文字数を400で割った値です。

SNSの上限

X（旧Twitter）は280の重み付き文字数を上限とし、日本語などの文字は1文字を2として数えるため、日本語では約140字が目安です。Instagramのキャプションは2,200字、noteのタイトルは15〜25文字程度が公式にすすめられています。上限や数え方はサービス側で変更されることがあるため、投稿前には公式の表示も確認してください。

オプションの違い

「連続する空白を1つに詰める」は、連続した半角スペース・タブ・全角スペースを1つの半角スペースとして数えます。「改行を除いて数える」は改行を数値から外します。どちらも表示する数値だけを変え、コピーされる本文には影響しません。
