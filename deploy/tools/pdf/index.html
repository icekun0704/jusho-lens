PDF結合・分割・回転・ページ番号

複数のPDFをまとめ、分け、回し、ページ番号を付けます。

またはこの枠にドラッグ&ドロップ（複数可）

1ファイル100MB、合計250MBまで。

暗号化されたPDFは復号できないため読み込めません。パスワードを解除したPDFを使ってください。

PDFはまだ選ばれていません。

    処理

    結合するには2つ以上のPDFを選びます。

    分割のしかた

    「1ページずつ」では、空のままなら全ページが対象です。

    回転は現在の向きに加算されます。

    各ページの余白に描画します。開始番号を5にすると、5から順に付きます。

    処理は端末内で行い、PDFはどこにも送りません。

    結果

    0出力ファイル
    0ページ数
    0 Bファイルサイズ
    —ページサイズ
    PDFを保存

      使い方

      PDFと設定は端末内だけで扱い、保存しません。

      1. PDFを選ぶか、枠にドロップします。
      2. 処理と設定を選びます。
      3. 結果を確認して保存します。

      PDF操作のしくみ

      選んだPDFはブラウザ内で読み込み、pdf-lib で組み立て直します。PDFの内容がサーバーへ送信されることはありません。処理できるのは、暗号化されていないPDFです。パスワードで保護されたPDFは、解除してから選んでください。

      結合

      一覧の上から順にページをコピーします。ドラッグ、または「上へ」「下へ」で順番を変えられます。「外す」で一覧から除けます。しおり、フォーム、添付ファイル、注釈は引き継がれないことがあります。

      分割

      ページ範囲は「1-3, 5」のように、ハイフンとカンマで指定します。「8-」は8ページ目から最後まで、「5-3」は逆順を意味します。「1ページずつ」を選ぶと、範囲内の各ページを別のPDFにし、ZIPでまとめて保存できます。

      回転

      指定したページを90度、180度、270度回します。回転は今の向きに加算されるため、続けて実行すると角度が重なります。対象ページを空にすると全ページが対象です。

      ページ番号

      位置、開始番号、書式、文字サイズを選びます。「1 / 10」の10は、開始番号を含めた最後の番号です。番号は本文の上に描画されるため、後から消したり編集したりはできません。必要な場合は元のPDFを残してください。

      制限と注意

      1ファイル100MB、合計250MBまでです。ページ数が多いPDFや画像の大きいスキャンPDFでは、端末のメモリ不足により処理に失敗することがあります。出力は新しいPDFになるため、作成者や更新日などのメタデータの一部は失われます。スキャンしたPDFの文字を検索可能にするOCR処理は行いません。対応ブラウザは、最新のChrome、Edge、Firefox、Safariです。
