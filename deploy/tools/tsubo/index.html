坪・平米・畳の変換

坪・平米（㎡）・畳を相互に換算します。畳は不動産表示の1.62㎡のほか、京間・中京間・江戸間・団地間の大きさを選べます。

3つの単位を換算する

どれか1つに数値を入れると、残り2つがその場で計算されます。1坪は400/121㎡（約3.30579㎡）として計算します。

値を入力すると換算結果が表示されます。

不動産広告の畳数は、1畳=1.62㎡として計算した目安です。実際の畳の大きさは地域や建物によって異なるため、部屋の広さは㎡（平米）で確認してください。

使い方

入力はブラウザ内で処理され、サーバーには送られません。

  1. 坪・平米・畳のどれか1つに数値を入力します。全角数字や桁区切りのカンマも使えます。
  2. 残りの2つの欄が自動で計算されます。入力した欄の値はそのまま残ります。
  3. 畳の種類を変えると、畳数の換算に使う1畳の面積が変わります。
  4. 小数桁を変えると、表示する桁数が変わります。末尾の0は表示しません。
  5. 下の表で、同じ面積を地域別の畳で表した枚数を比べられます。

坪・平米・畳について

坪は不動産や土地の面積でよく使われる尺貫法の単位、平米（㎡）はメートル法の面積、畳は部屋の広さを表す日本の慣用単位です。この道具は、この3つを同じ面積として相互に換算します。

坪と平米の関係

1坪は400/121平方メートルで、小数にすると約3.30579㎡です。逆に1㎡は約0.3025坪になります。坪は1間（6尺）四方の面積で、1尺は10/33メートルなので、1坪は(60/33)²=400/121㎡となります。不動産の土地面積は坪と㎡のどちらでも表示されるため、広さを比べるときは同じ単位にそろえると分かりやすくなります。

畳の大きさは地域で違う

畳1枚の面積は地域や建物によって異なります。代表的なものとして、京間（本間）は約1.824㎡、中京間は約1.656㎡、江戸間は約1.549㎡、団地間は約1.445㎡が目安として使われます。一方、不動産広告では、不動産の表示に関する公正競争規約により、畳1枚を1.62㎡として計算する決まりがあります。そのため、広告の「10畳」は実際の畳の枚数や部屋の広さと一致しないことがあります。

表示と実寸は異なる

不動産広告の畳数は目安であり、実際の部屋の広さとは異なります。マンションの面積は壁の中心線で測る壁芯（かべしん）で表示されることが多く、戸建てでは内法（うちのり）で測る場合もあります。柱や壁、押し入れ、バルコニーの扱いによっても有効な広さは変わります。契約や重要事項説明では、畳数ではなく㎡の面積を確認してください。
