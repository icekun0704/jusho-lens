URLエンコード

文字列をURL用にエンコード・デコードし、フォーム送信の方式にも対応しています。

変換の向き

フォーム方式では、空白を + として扱います。

変換はUTF-8で行います。Shift_JISの文字列は正しく変換できません。

Ctrl（Macは⌘）+ Enter でも変換できます。

使い方

結果はボタンからコピーできます。

  1. エンコードかデコードを選びます。
  2. 文字列を入力して実行します。
  3. 結果を確認してコピーします。

URLエンコードのしくみ

URLでは使えない文字を「%」と2桁の16進数で表します。日本語はまずUTF-8のバイト列にし、1バイトずつ%XXにします。たとえば「日」は「%E6%97%A5」です。ここではブラウザのencodeURIComponentとdecodeURIComponentを使います。

通常方式とフォーム方式の違い

encodeURIComponentは英数字と - _ . ! ~ * ' ( ) を残し、それ以外を%XXにします。空白は%20です。フォーム送信のapplication/x-www-form-urlencodedでは空白を+で表し、! ' ( ) ~ も%XXにします。クエリでは+が空白を意味しますが、URLのパスでは+は文字どおりのプラスです。フォーム方式はフォームのデータにだけ使ってください。

エラーになる例

デコードでは、%の後ろに2桁の16進数がないとエラーになります。正しい16進数でもUTF-8として不正なバイト列（例: %FF単独）は戻せません。%そのものを含めたいときは、あらかじめ%25にエンコードされている必要があります。エンコード済みの文字列をもう一度エンコードすると%が%25になり、二重エンコードになります。元の文字列がUTF-8かも確認してください。
