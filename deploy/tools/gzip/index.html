gzip圧縮・解凍

テキストを .gz に圧縮し、圧縮ファイルを開いて中身を確認できます。

このブラウザは CompressionStream / DecompressionStream に対応していないため、圧縮・解凍を利用できません。Chrome または Edge の 80 以降、Firefox 113 以降、Safari 16.4 以降の最新版でお試しください。

圧縮（テキスト → .gz）

テキストを UTF-8 として gzip 圧縮します。上限は 20MB です。

拡張子がなければ「.gz」を付けます。

—圧縮後（.gz）

解凍（.gz → テキスト）

.gz ファイルを選んで解凍します。上限は 20MB です。

—.gz のサイズ
—解凍後のサイズ
—展開倍率

使い方

  1. テキストを入れて圧縮します。
  2. .gz ファイルを選んで解凍します。
  3. 中身を確かめて保存します。

gzip 圧縮と解凍

テキストを gzip 形式で圧縮して .gz ファイルとして保存し、.gz ファイルは解凍して中身を表示・保存できます。処理はブラウザの CompressionStream / DecompressionStream で行います。

gzip とは

gzip は RFC 1952 で定められた圧縮ファイル形式で、中身は DEFLATE という可逆圧縮です。同じ記号や単語が繰り返されるテキストほど小さくなり、元のデータは完全に復元できます。このツールが作る .gz には元のファイル名や更新日時は記録されません。

削減率と注意点

削減率は、元の UTF-8 バイト数に対して圧縮後がどれだけ減ったかの割合です。日本語は1文字3バイトなので、文字数より元サイズが大きくなります。短いテキストではヘッダとトレーラ（約18バイト）の分だけ増え、削減率がマイナスになることがあります。

CompressionStream は Chrome・Edge 80 以降、Firefox 113 以降、Safari 16.4 以降が目安です。非対応のブラウザでは警告を出してボタンを無効にします。一度に扱えるのは 20MB までで、.tar.gz は解凍しても tar 形式のバイト列になるためテキストとしては表示されません。
