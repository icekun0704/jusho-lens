IP・接続チェック

いま使っている回線のIPアドレスと、ブラウザが公開している接続情報をまとめて確認します。

IPアドレスを調べる

このツールはIP確認のために ipwho.is へ問い合わせます。それ以外の入力は送信しません。通信が起きるのは「調べる」を押したときだけです。

IPアドレスから取得した接続情報

位置は回線事業者の登録情報にもとづく概略です。VPN や携帯回線では、実際の場所と異なることがあります。

このブラウザの情報

ページを開いた時点でブラウザから読み取れる値です。この部分はサーバーへの問い合わせを行いません。

使い方

外部へ問い合わせるのはIP情報の取得だけです。ブラウザ情報の表示は端末内で完結します。

  1. 「調べる」を押すと、ipwho.is に問い合わせて現在のIPアドレスを取得します。8秒で応答がない場合は中止します。
  2. IPアドレス、国・地域、都市、ISP、ASN、タイムゾーン、緯度・経度が表示されます。
  3. 「結果をコピー」で表の内容をプレーンテキストとして取り出せます。下のブラウザ情報は常に表示され、通信は発生しません。

IP・接続チェックについて

IPアドレスは、インターネット上の通信をやり取りする単位に付いた番号です。ページを開いたり、動画を見たりするたびに、接続元のIPアドレスは相手のサーバーに伝わります。ここでは、いま使っている回線が外部からどう見えているかを確認できます。

位置情報はどこまで正確か

国・地域・都市といった位置情報は、主にISP（インターネット接続事業者）が登録した情報をもとに推定されます。同じ回線でも接続のたびにIPが変わる場合があり、VPNやプロキシ、携帯回線を使っていると、実際の居場所とは違う地域が表示されることがあります。緯度・経度も目安の概略値で、番地や建物を特定するものではありません。

ブラウザ情報の扱い

ユーザーエージェント、言語、タイムゾーン、画面サイズなどは、ブラウザがページに渡している値で、JavaScriptから読み取れます。端末の種類や設定の確認に役立ちますが、ユーザーエージェントは書き換えられるため、端末を確実に判定するものではありません。オンライン状態とCookieの有効・無効も同じく端末内の情報です。

外部への通信

IP情報の取得のため、このページは ipwho.is に HTTPS で問い合わせます。送信されるのは通常のHTTPリクエスト（接続元IPアドレスやユーザーエージェントなどを含みます）だけです。このツールに入力する項目はありませんし、取得した内容を保存したり別のサービスへ送ったりする処理もありません。

ipwho.is の無料枠は1日あたり1,000リクエストで、ブラウザからの利用はサイトのドメイン単位で数えられます。上限に達すると、24時間ほど取得できないことがあります。その場合もブラウザ情報の表示は変わりません。
