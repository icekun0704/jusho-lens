IP・接続チェック

いま使っている回線の IP アドレスと接続情報を確認します。

IPアドレスを調べる

問い合わせ先はこのサイトのサーバーだけで、外部の位置情報サービスへは送りません。

IPアドレスから取得した接続情報

位置は回線事業者の登録情報にもとづく概略です。VPN や携帯回線では実際の場所と異なります。

このブラウザの情報

ページを開いた時点でブラウザから読める値です。通信は発生しません。

使い方

IP 情報はこのサイトのサーバーが返します。ブラウザ情報は端末内で読み取ります。

  1. 調べるを押します。
  2. IP・国・タイムゾーンを見ます。
  3. 必要なら結果をコピーします。

IP と接続情報

IP アドレスは、インターネットの通信に付いた番号です。ページを開いたり動画を見たりするたびに、接続元の IP は相手のサーバーに伝わります。ここでは、いま使っている回線が外部からどう見えているかを確認できます。

位置情報の正確さ

国・地域・都市は、主に ISP が登録した情報をもとに推定されます。同じ回線でも接続のたびに IP が変わることがあり、VPN やプロキシ、携帯回線では実際と違う地域が表示されることがあります。緯度・経度も概略値で、番地や建物を特定するものではありません。

通信先とブラウザ情報

IP 情報の取得は、このサイトのサーバーに置いた ip.php だけで行います。外部の位置情報サービスには問い合わせません。サーバーが見られるのは接続元の IP と、Cloudflare が付ける国コードだけです。そのため都市名・ISP・ASN・緯度経度は表示されません。

ユーザーエージェント、言語、タイムゾーン、画面サイズは、ブラウザがページに渡している値で、端末内で読み取れます。ユーザーエージェントは書き換えられるため、端末を確実に判定するものではありません。
